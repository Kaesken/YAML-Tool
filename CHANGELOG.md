# YAML Tool — fixes for the audit (ec12f3d)

Files: `YAMLTool.html` and `index.html` (identical), `lich-yaml-settings.html`, and a new `_headers` (CSP for Cloudflare).

## What changed

- **The file is built as data, not text.** buildYAML now builds a JavaScript object and writes it with the bundled js-yaml, so every value is quoted when it needs to be. The previews show slices of the same document, so they always match the download.
- **Only real choices are written.** Every toggle starts at dr-scripts base.yaml's value, and a key is written only when it differs from base.yaml. Hashes (skinning, pick, thanatology, zombie, astrology_prediction_skills, charged_maneuvers) are merged over base.yaml's hash, because Lich replaces whole top-level keys.
- **Checks before Copy and Download.** Real problems (missing name, Fang Cove without an override town, burgle without a room or loot container, Light/Dark immortal without a water holder, half-filled famine healing, non-numeric room ids, bad money format, YAML errors in extra settings) stop the save with a message. Everything else (no training list, no hunting zone, a hunt with no stop, cambrinth without a cap) is a warning you can save past. The Generate step lists them.
- **Nothing is lost from an existing profile.** "Start from your existing YAML" fills the form from your file; every key the form can't show, and any key the form would write differently, is written back exactly as it was. Tested on the 229 sample profiles in dr-scripts: every one Ruby can load comes back identical, except one that merges an empty anchor (`<< : &name`), which is read as an empty map.
- **Any base.yaml setting.** "Add any base.yaml setting" and "Browse base.yaml by section" cover all 662 keys, each starting at its base.yaml value, plus include / union_keys and a raw Extra YAML box.
- **Your work is saved in the browser** as you type, with a "Start over" button.
- **Data:** live data loads from `main` (8 s timeout) and now includes base.yaml and base-town.yaml; the offline copy is regenerated from dr-scripts 6c70da3 by the same transforms.
- **New or reworked:** several hunts with stop_on/stop_on_low/before/after/during, crossing-training, healing/safe-room fields, burgle and locksmithing options, looting lists, named gear sets and full gear flags, spell slots that match the scripts (incl. combat_spell_training and crossing_training_sorcery), Engineering crafting, guild settings for every guild.
- **Settings index** rebuilt from dr-scripts 6c70da3 / lich-5 879b143 with correct descriptions, sections, "Copy as YAML" and deprecation/run-time notes.

## How it was checked

- `harness/checks.js`: 50 executable checks, one per finding group (the ids are listed below as **check**). All 50 fail on the original and pass on the fixed file. Each builds the YAML in a browser DOM (jsdom) and loads it with Ruby Psych, as Lich does.
- `harness/scenarios.js`: drives the whole form for all 11 guilds (pastes, toggles, two hunts, spells in every list, waggle sets, crafts, extra settings, a Ruby regexp) and checks the file loads in Psych with no page errors.
- `harness/roundtrip.js`: imports each of the 229 sample profiles in dr-scripts and checks that base.yaml merged with the output equals base.yaml merged with the original. Result: identical for all of them except Quillith-setup.yaml (empty-anchor merge, see above); profiles Ruby itself cannot load are skipped.
- Live and bundled base.yaml produce identical defaults.
