;Lich YAML Settings Index

Every setting in dr-scripts' profiles/base.yaml, plus every setting a script or the Lich DragonRealms library reads that isn't in that file. Pick a script to see exactly which settings it uses, then copy them as YAML.

How this was built. Keys, defaults, comments and section names come from profiles/base.yaml. "Read by" lists every file where code accesses the key on a settings object (settings.key, @settings.key, get_settings.key, or a literal settings['key']/fetch/dig). Dashed chips are Lich core library files rather than dr-scripts.
Direct reads only. A script also depends on settings read by the library helpers it calls. Picking forge.lic shows the ten keys forge reads itself; the crafting magic, hometown and private-forge keys it uses come through common-arcana.rb and common-crafting.rb, so check those under "Lich lib" in the script list too.
Limits. Some scripts build key names at runtime, so those keys can show "no code reference" even though they're used: . Settings nested inside a hash (for example the entries inside waggle_sets or bonebug) are shown in the parent's default, not as their own rows. Keys marked "Not in base.yaml" show the first line of code that reads them, which usually reveals the type and fallback.
